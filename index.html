Hush Search

Type anything: a search, a website (youtube, instagram.com), or “download python”. Hush opens it in a new tab. No server, no logs, no tracking. Sites open in a new tab because Google, WhatsApp and Instagram do not allow themselves to be embedded in other pages.

Pipeline: tokenize → drop stop words → light stemming → inverted index (term → documents) → BM25 ranking (k1 = 1.5, b = 0.75) → snippet with highlighted matches. Everything is plain JavaScript in this one file.
